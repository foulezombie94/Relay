# SQL d'origine — archive

Les sept fichiers de ce dossier sont les scripts initiaux conservés pour retrouver l'origine du schéma. Ils ne constituent pas un deuxième chemin de déploiement et ne doivent pas être rejoués sur une base existante.

L'historique canonique est [../migrations](../migrations), dans l'ordre des versions. Les corrections ultérieures, RLS et fonctions récentes s'y trouvent. Les tests sont dans [../tests](../tests).

Ce rangement ne change aucun contenu SQL, aucune migration appliquée et aucune donnée Supabase. Voir [le déploiement](../../docs/operations/deployment.md).
